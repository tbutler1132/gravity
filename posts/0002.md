title: The Lifecycle of Software Objects
week: 2026-W36

Every Sunday, this project will publish a record of everything that changed in the week behind it.

0000 was a vow. 0001 was the grammar. But a vow you cannot check is only a feeling, and drift never announces itself. That Sunday record is the machinery: it turns orientation into something you can verify instead of something you assume. A few new kinds of things have to exist before it can be written.

Three new types will be introduced:

1. Post
2. Change
3. Release

A Post is a published piece of writing. It exists to state intent. Before the project changes in a way that matters, the reasoning has to be written down and made public, where it can be read and argued against. Going with the flow is another name for gravity. A Post is the act of deciding instead of being pulled.

A Change is a single alteration to the project. Every Change has a magnitude: major, minor, or patch. This is borrowed from general software versioning. Patches fix, minors add, and majors alter what the thing is. Naming the magnitude is a small act of judgment, made in the open, every time. The point is not precision. The point is a shared language for how the thing moves. Every Change carries its own record, so nothing lands unexplained; the Post is reserved for the ones that change what this is.

A Release is an end of week ritual. Weeks run Monday to Sunday, so a Release lands on the day off: a weekly act of record gathering every Change that landed that week. It is the point where the week stops being private effort and becomes something witnessed. A week with nothing in it still gets a Release. An empty Release is drift, dated and visible.

Major Changes only ship after a Post about it has been published. The Post states the intent and the rationale for the Change. This makes majors expensive on purpose. They should be rare, and they should cost something to make.

This post is a major Change. Three new types alter what this is. So it ships the only way a major can, written down first.
